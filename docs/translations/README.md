# English readings

The terminal offers **Original · English** where an English reading is available. English readings are machine translations of the published text, generated with OpenAI GPT-4.1 mini. They are reading aids, not substitutes for the source.

Record identifiers, links, numerical tokens, redaction marks and line breaks are protected during translation. The source wording remains accessible under **Original**. Translation can still alter nuance or introduce errors; quotations should be checked against that source.

Images, PDFs, audio and source-code files are not translated. No withheld text is reconstructed. Each derivative is tied to the checksum of its published source; the site build rejects a derivative if that source has changed.
