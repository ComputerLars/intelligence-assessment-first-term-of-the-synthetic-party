## A26-S69: Historical script

#!/bin/bash

###############################################################################
# Why this script works:
#
# 1. We need xz to decompress .xz files, so we check if unxz is installed.
#    If it's not, we install Homebrew and then xz.
#
# 2. We define URLs, filenames, and the disk location. For you, /dev/disk4
#    is the SD card, and /dev/rdisk4 is the raw device which is faster to write to.
#
# 3. We go into ~/Downloads so we know where the file lands. Then we download
#    the latest 64-bit Raspberry Pi OS with curl, saving it as an .xz file.
#
# 4. We decompress the .xz with unxz, leaving a .img behind.
#
# 5. We unmount the disk to ensure macOS isn't using it. This readies it for dd.
#
# 6. We use dd to write the .img directly to the raw SD card device at a 1MB
#    block size with syncing. conv=sync pads input blocks if needed.
#
# 7. sync flushes writes to the disk so data is fully guaranteed on the card.
#
# 8. Finally, diskutil eject ensures a clean detach so you can remove the card.
###############################################################################

# Check for xz/unxz presence; install if missing
if ! command -v unxz >/dev/null 2>&1; then
  echo "Installing xz..."
  /usr/bin/ruby -e "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/master/install)"
  brew install xz
fi

# Download configuration
OS_URL=https://downloads.raspberrypi.org/raspios_arm64_latest
DEST_DIR="$HOME/Downloads"
IMG_NAME="raspberry_pi_5_os_latest.img"
DISK="/dev/disk4"
RAW_DISK="/dev/rdisk4"

cd "$DEST_DIR"
echo "Downloading OS image from $OS_URL..."
curl -L "$OS_URL" -o "$IMG_NAME.xz"

echo "Decompressing $IMG_NAME.xz..."
unxz "$IMG_NAME.xz"

echo "Unmounting partitions on $DISK..."
diskutil unmountDisk "$DISK"

echo "Writing $IMG_NAME to $RAW_DISK..."
sudo dd if="$IMG_NAME" of="$RAW_DISK" bs=1m conv=sync

echo "Flushing writes..."
sync

echo "Ejecting $DISK..."
diskutil eject "$DISK"

echo "Done. You can now remove the SD card."

Performance:
Zoriana Blyskavak [████]

Zoriana Blyskawka: The Futuristic AI-Poet of a Ukraine That Never Bowed to
the USSR

In an alternative reality where Ukraine evolves independently, free from
the destructive influence of the Soviet regime, Zoriana Blyskawka emerges
as a symbol of a modern, sovereign culture. More than just a poet, she is
the technological embodiment of a futuristic sensibility—an algorithm
intertwined with the spirit of the avant-garde.

Zoriana merges the precision of mechanics with the emotional depth of
poetry, uncovering new registers of language and sound. Created as an
advanced AI model, she was developed in collaboration with the Kharkiv
Museum of Literature, drawing from the archival collections of Ukrainian
Futurists, particularly the *Semafor* publishing house from the 1920s. Her
work is both a tribute to the past and a bold leap into the future—a poetry
never silenced by ideological chains, but instead erupting with visions of
a world that could have been.
