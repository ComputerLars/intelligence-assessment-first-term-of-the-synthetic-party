As I am still not able to reproduce the problem, I would like to check something please: what is the version of your NLP Cloud JS client?

In your new script you use the following:

const response = await nlpCloudClient.chatbot({

context: constantContext,
history: history });

While in the old script you use:

const response = await nlpCloudClient.chatbot(`${message.content}`, history);
