# Danish-language screen

**METHOD-A15-A08/2026-10-26**

Of the 4,808 completed exchanges under labels other than Computer Lars, **3,327 inputs are coded as non-Danish or mixed-language: 69.2%**. The denominator includes unclassified inputs.

| Classification | Inputs |
|---|---:|
| Non-Danish or mixed-language | 3,327 |

| Unclassified | 283 |
| Total under other labels | 4,808 |

The unit is the complete input preceding one `-> Leder Lars:` reply in [A15-D02](../../../data/A15-D02.txt), before this edition’s further redactions. The leading `!` and surrounding whitespace are stripped. The parser identifies 5,097 completed exchanges: 289 under the Computer Lars label and 4,808 under other labels. Ten speaker fragments without a reply are excluded. These are exchanges, not distinct people.

## Classification

The baseline uses `langid` 1.1.6 with its unrestricted language set. Inputs with fewer than ten Unicode alphabetic characters remain unclassified. No classifier-score threshold determines inclusion.

Counting eligible inputs labelled other than `da` without correction gives 3,653 (76.0%). The recorded review covers all 307 eligible neighbouring-language labels (`nb`, `no`, `nn`, `sv`), 101 rarer-language labels outside the principal languages, Danish lexical cues assigned other languages, low-score English labels, and Danish labels with English cues or unusual wording. Danish-compatible neighbouring-language cases are grouped with Danish; [54 row-level adjudications](danish_adjudications.json) record exceptions. Clear Norwegian inputs remain non-Danish. Norwegian and Swedish are not excluded categorically.

Mixed-language inputs combine Danish with another language beyond proper names and common technical product names; this includes English questions around quoted Danish material. Of the 283 unclassified inputs, 275 fall below the length threshold and eight are code, noise or name-only cases.

This is an automated screen with targeted correction, not a complete manual census. The recorded judgments are fixed research inputs. Reproducing their arithmetic does not independently validate each judgment. The result establishes neither nationality, voting rights, abstention nor a number of participants.

The earlier Scandinavian-group screen gave 3,346/4,808 (69.6%). It counts labels outside Danish, Norwegian and Swedish, rather than against Danish specifically. Further Danish false positives and eight additional unclassified inputs explain the lower Danish-specific result. Neither screen substantiates the older 3,454-input figure from a different, fragment-level procedure.

## Reproduction

The included row classifications and fixed adjudications reproduce the reported arithmetic without prompt bodies or participant names. From this directory, using Python 3:

```sh
python apply_danish_adjudications.py --source-index whole_input_language_index.csv --out /path/to/results/danish
```

[Correction script](apply_danish_adjudications.py) · [Corrected counts](danish_specific_counts.json) · [Corrected row classifications](danish_specific_index.csv)

Reclassifying the original inputs requires the earlier analysed witness and its separately retained checksum. The redacted text in this edition is not a substitute for that witness. With access to the witness and the [pinned dependencies](requirements.txt):

```sh
python -m pip install -r requirements.txt
python recount_whole_input_languages.py --source /path/to/original-analysed-witness.txt --expected-source-sha256 ORIGINAL_WITNESS_HASH --out /path/to/results/baseline
```

[Baseline counter](recount_whole_input_languages.py) · [Baseline counts](language_counts.json) · [Baseline row classifications](whole_input_language_index.csv)

The baseline counter recreates row classifications and core count fields; some descriptive metadata in the recorded JSON is not generated by the script. The correction script checks the baseline-index checksum and reproduces the corrected CSV and counts. All outputs must be written outside the edition.

## Supplied-source limitation

At rows 4546, 4562 and 4567, participant-shaped labels occur inside submitted code. The parser starts units at those labels, omitting the preceding prompt lead-ins at rows 4544, 4560 and 4566. The labels do not establish three additional people. Each reply is counted once, so the total is unchanged: two affected units were classified non-Danish or mixed and one unclassified. No earlier unaltered witness has been located; missing words and code declarations have not been reconstructed.
